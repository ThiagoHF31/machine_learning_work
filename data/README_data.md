# Project data – next-day weather prediction for Macau

| File | Source | Content |
|---|---|---|
| `macao_teacher_data.csv` | Visual Crossing Weather Query Builder (source suggested in the specification) | 15 days of **forecast** (11/10/2026 to 25/10/2026) in US units. Not enough history for training; kept only as a format reference. |
| `macao_openmeteo.csv` | Open-Meteo Historical Weather API (ERA5 reanalysis) | Raw daily history for Macau, 2014-01-01 to 2025-12-31 (4383 days), with the original API column names. |
| `processed/macau_features_processed.csv` | generated by the notebook | Feature matrix and targets used by the models. |

* Location: Macau (lat 22.1987, lon 113.5439), time zone Asia/Macau.
* To reproduce: run `notebooks/weather_prediction_macau.ipynb`. If `macao_openmeteo.csv` is missing, the notebook downloads it from
  https://archive-api.open-meteo.com/v1/archive (no account needed) with the variables listed in `notebooks/weather_utils.py`.
* To check in a browser (first 10 days, CSV):
  https://archive-api.open-meteo.com/v1/archive?latitude=22.1987&longitude=113.5439&start_date=2014-01-01&end_date=2014-01-10&daily=temperature_2m_max,temperature_2m_min,precipitation_sum,cloud_cover_mean&timezone=Asia%2FMacau&format=csv
